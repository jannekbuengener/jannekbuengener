### 4. Agent Orchestration Case

Coordinated multiple AI agents and tools through a bounded **Agent Room** architecture, routing work to **best-fit execution lanes** while treating all provider output as **evidence, not truth**.

**Core question:** How do you coordinate multiple AI agents and tools without blindly trusting their output?

**What it demonstrates:**
- Multi-agent orchestration
- Bounded authority per lane
- Task-specific routing based on risk, cost, and readiness
- Independent validation of evidence
- Repair/merge convergence cycles

_See the [public portfolio excerpt](https://github.com/jannekbuengener/gpt-mcp-server/blob/main/docs/PUBLIC_PORTFOLIO_EXCERPT.md) for the sanitized case summary._

## How I work

1. I define the problem and desired outcome.
2. I decompose work into bounded tasks.
3. I select and orchestrate appropriate AI systems and tools.
4. I define acceptance criteria and system boundaries.
5. I validate outputs against evidence.
6. I iterate when reality does not match the claim.

Substantial implementation work is AI-assisted. My core contribution is system design, product thinking, orchestration, requirements, validation and quality control — not claiming manual authorship of every code line.
