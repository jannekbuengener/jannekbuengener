## How I work

1. I define the problem and desired outcome.
2. I decompose work into bounded tasks.
3. I select and orchestrate appropriate AI systems and tools.
4. I define acceptance criteria and system boundaries.
5. I validate outputs against evidence.
6. I iterate when reality does not match the claim.

Substantial implementation work is AI-assisted. My core contribution is system design, product thinking, orchestration, requirements, validation and quality control — not claiming manual authorship of every code line.
